# РостПро — интерактивный гайд

Продающий веб-гайд по ролям (собственник, операционный директор, финансовый директор, ГИП, руководитель подразделения, исполнитель) для холодных лидов.

## Разработка

```bash
npm install
npm run dev
```

Форма заявки (`/api/contact`) — серверная функция, под чистым `vite dev` не работает.
Для локальной проверки формы целиком нужен `vercel dev` с настроенными переменными окружения (см. `.env.example`).

## Сборка

```bash
npm run build
```

## Деплой

Проект рассчитан на Vercel: статика собирается из `src/`, `api/contact.js` разворачивается как serverless-функция автоматически, без дополнительной настройки.

В настройках проекта на Vercel нужно задать переменные окружения из `.env.example` — те же значения SMTP, что настроены для сайта planr-site, чтобы заявки с гайда и с сайта приходили на один и тот же адрес.
