# Семантическое ядро — что уже отражено на сайте

Источник: `rostpro-semanticheskoe-yadro_2.xlsx` (сборка 03.08.2026, 288 запросов).
Дата этой правки: 04.08.2026.

**Область охвата:** только 6 страниц, которые уже существуют на сайте (`/`, `/technologies`,
`/pricing`, `/contact`, `/features`, `/about`). Лист «Структура сайта» из файла просит ещё
~26 новых посадочных (`/features/*`, `/for/*`, `/roles/*`, `/compare/*`, `/blog/`) — это
отдельный, гораздо больший этап, к которому пока не приступали.

Все формулировки ниже — обычный серверный HTML, одинаковый для любого посетителя и любого
бота (проверено: в коде нет `middleware.ts` и нет ветвления по User-Agent/IP) — клоакинга нет
по построению.

## `/` — Главная (из 51 запроса, нацеленного на этот URL)

**Учтено:**
- «система управления проектным бизнесом» — дословно, в `meta description`.
- «ERP» — в тексте CTA-блока («единая ERP-платформа для управления проектами...»).

- Бренд «ростпро» / «rostpro» — органически везде (лого, заголовки, тексты).

**Не учтено:**
- Кластер «Отзывы и внедрение» (4 запроса: *…отзывы*, *внедрение системы управления проектами
  в компании*, *сроки внедрения erp для проектной организации*) — не добавлял, так как
  реальных отзывов клиентов на сайте нет, а выдумывать их нельзя.
- Кластер «Второй бренд (конфликт)» (4 запроса: *planr*, *планр*, *planr cloud*, *планр
  система управления проектами*) — **намеренно не используется**. По прямому указанию на
  сайте не должно быть ни одного упоминания старого названия. Уже пробовал добавить
  нейтральное «(ранее — PlanR)» для этого кластера и убрал по вашей правке — решение
  зафиксировано, дублировать не нужно.
- Остальные ERP/PSA-синонимы кластера «Категория продукта» (~30 формулировок вроде
  *erp для проектных организаций*, *psa система*, *platform для управления портфелем
  проектов* и т. п.) — использована только одна репрезентативная фраза плюс «ERP» как общий
  термин; дословно остальные варианты в текст не включались (риск переспама одной и той же
  идеи).

- Кластер «Импортозамещение / реестр»: фразы вида *система управления проектами в реестре
  отечественного по*. Сам файл (лист «Легенда») прямо помечает этот факт как непроверенный:

  ПО** — если РостПро там действительно зарегистрирован, дайте номер записи, и это можно
  честно добавить.
- Кластер «Формат поставки» (P2): *коробочная версия*, *on premise*, *облачная версия*.
  Не добавлял, потому что не знаю, есть ли у продукта реальная on-premise/коробочная поставка
  для клиентов (в отличие от того, что сам сайт крутится в облаке — это про сам сайт, не про

## Ограничения, которые я сознательно соблюдал

1. **Никаких упоминаний «PlanR»/«планр»** — ни в тексте, ни в метаданных, нигде.
2. **Не заявлено включение в реестр отечественного ПО** — источник сам пометил это как
   непроверенный факт.
3. **Не придуманы отзывы клиентов** — нет реального контента, фабриковать нельзя.
4. **Не заявлена on-premise/коробочная поставка** — нет подтверждения, что это реальная опция.
5. **Ни одной строчки кода с проверкой User-Agent/IP** — весь текст виден одинаково и людям,
   и поисковым ботам.
